# public/assets/

Arquivos estáticos servidos direto pelo navegador sem passar pelo processo de build do Vite — imagens, ícones, SVGs dos jogos (ex.: criaturas da V0.13, Memória das Profundezas).

Diferente de imagens importadas dentro de `src/` (que passam pelo bundler), o que está aqui é referenciado por caminho direto (ex.: `/assets/nome.svg`).
