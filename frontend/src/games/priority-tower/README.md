# Torre de Prioridade

Jogo de lógica e dedução. O jogador recebe um conjunto de itens e pistas sobre suas posições, relações e proximidades. A tarefa é montar a ordem correta do primeiro ao último lugar.

## Mecânica

- O jogador começa com 60 segundos.
- Cada desafio possui de 4 a 7 itens.
- As pistas são geradas para definir uma única ordem possível.
- O jogador seleciona os itens na ordem em que acredita ser correta.
- Uma resposta correta gera um ponto e pode aumentar o nível.
- Respostas incorretas contam como tentativa, mas permitem tentar o mesmo desafio novamente.
- A partida envia score, accuracy, tempo médio de reação e nível alcançado para o backend.
