# games/memory-match/

Jogo da Memória (Pares Clássico) — V0.2 do roadmap. Grade de cartas, lógica de virar/comparar pares, contagem de tentativas e tempo.

Contém `MemoryMatch.jsx` (componente visual) e `useMemoryMatch.js` (toda a lógica do jogo, isolada em hook). Lógica específica deste jogo fica aqui dentro, não em `hooks/` (que é só pra hooks compartilhados entre vários jogos).
