# pages/

Telas completas da aplicação, montadas a partir dos componentes e hooks (`Home.jsx`, `GamePage.jsx`, `Dashboard.jsx`, `Login.jsx`, `Settings.jsx`).

Uma page pode ter lógica de "orquestração" (buscar dados, decidir o que renderizar), mas a lógica de UI reutilizável deve estar em `components/`, não copiada aqui dentro.
