# types/

Definições de formatos de dados usados em mais de um lugar do frontend — por exemplo, o formato de um resultado de partida (`score`) ou de um objeto de usuário retornado pela API.

Não é tipagem TypeScript (o projeto é JS puro); aqui entram objetos de referência, JSDoc de formato, ou constantes que descrevem a "forma" dos dados trocados com o backend. Serve pra consulta rápida em vez de ficar adivinhando os campos de um objeto vindo da API.
