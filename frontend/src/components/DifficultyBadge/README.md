# components/DifficultyBadge/

Selo/indicador visual do nível de dificuldade atual do jogador num jogo (ex.: "Nível 3", "Difícil").

Componente ligado à V0.14 (Dificuldade Adaptativa) do roadmap — não deve conter a lógica de cálculo de dificuldade em si, só exibir o valor que o hook `useAdaptiveDifficulty` calcular.
